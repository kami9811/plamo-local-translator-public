# Repository working rules

- Do not commit models, runtime binaries, local data, pairing keys, private paths, or browser profiles.
- Keep the MIT application license separate from PLaMo model and generated-output terms.
- Preserve Built with PLaMo attribution and the bundled agreement when distributing generated examples or exports.
- Restore the previously active GitHub account after any temporary account switch.
- Verify changes with the relevant Python, TypeScript and browser checks; distinguish real inference from test doubles.
