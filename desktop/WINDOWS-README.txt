PLaMo Local Windows コントローラー 0.1.1

初回セットアップ後の日常操作を、ターミナルなしで行うアプリです。
先にWSL2、Python、モデル、Chrome拡張のセットアップを完了してください。

【実行先を設定する：初回だけ】
1. ZIPを「すべて展開」し、PLaMoLocalController.exeをダブルクリックします。
2. 「実行先の設定」を開きます。
3. WSLの「一覧から選ぶ」を押し、翻訳環境を用意したUbuntu等を選びます。
   1つしか使っていない場合、WSL名は空欄（既定）のままでも使えます。
   一覧が出ない場合はPowerShellで wsl --list --quiet を実行して名前を確認します。
4. 「フォルダーを選択…」を押し、WSL内の翻訳プロジェクトを選びます。
   scriptsフォルダーとruntime-manifest.jsonが入っている場所です。
   アプリのZIP、exe、拡張のdist、scripts自体は選びません。
   エクスプローラーではアドレスバーに \\wsl.localhost\ と入力し、
   WSL名 → home → 自分のユーザー → プロジェクトの保存先の順に探します。
   共有パスから選ぶと、WSL名とLinux側のパスは自動で入力されます。
   別の場所に保存した場合は、その場所を選びます。
   見つからないときは、セットアップに使ったUbuntuのターミナルでプロジェクトへ
   移動してpwdを実行し、表示された /home/… のパスを貼り付けてください。
   WSL共有パスの貼り付け、フォルダーのドラッグにも対応します。
5. 「確認して保存」を押します。API・モデルはまだ起動しません。

【起動してChromeで使う】
1. このアプリの「起動」を押します。
2. 「接続キーを表示」→「コピー」を押します。
3. Chrome右上のパズル → PLaMo Local →「原稿・用語集・接続設定」を開きます。
4. 左メニューの「接続と設定」を選び、「接続キー」欄へ貼り付けて「接続する」。
5. 上部に「接続済み · PC内で処理」が表示されたら準備完了です。
   同じキーなら、次回から登録をやり直す必要はありません。
6. 通常のWebページで英文を選択 → 右クリック →「PLaMoで選択文を翻訳」。
   最初の翻訳時はモデルの準備を待ちます。
7. 終了時は「停止」を押します。ウィンドウを閉じるだけではAPIは停止しません。

拡張がChromeにない場合は、先に拡張を追加してください。画面付きの手順：
https://github.com/kami9811/plamo-local-translator-public/blob/controller-v0.1.1/docs/DESKTOP.md#chrome-extension

動作環境：Windows 10/11、.NET Framework 4.7.2以降、WSL2。
重み、原稿、Python、WSL、接続キーはこのZIPに含みません。
別のフォルダーから起動したAPIや別の接続キーは扱いません。
設定の保存先：%LOCALAPPDATA%\PLaMoLocalTranslator\controller.json
保存するのはWSL名・実行先・テーマのみです。設定を消す場合はアプリを閉じて削除します。
APIの原稿・結果・接続キーはプロジェクト内の.data/に保存されます。
