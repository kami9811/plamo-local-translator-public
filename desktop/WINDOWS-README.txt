PLaMo Local Windows コントローラー 0.1.0

1. ZIPをすべて展開し、PLaMoLocalController.exeをダブルクリックします。
2. 「実行先の設定」を開き、WSL内のプロジェクトフォルダーを指定します。
   Linuxの絶対パス、またはエクスプローラーの \\wsl.localhost\... のパスを貼り付けます。
   WSLのフォルダーを入力欄へドラッグすることもできます。
3. WSL名は通常空欄のままで構いません。「設定を保存」を押します。
4. 「起動」でローカルAPIを起動します。「接続キーを表示」→「コピー」で拡張へ登録します。
5. 終了するときは「停止」を押します。ウィンドウを閉じるだけではAPIは停止しません。

動作環境：Windows 10/11、.NET Framework 4.7.2以降、WSL2。
モデル・Python・Chrome拡張の初回セットアップは先に完了させてください。
このアプリにモデルの重みや推論ランタイムは含まれていません。

起動・停止・キー表示はボタンを押したときだけ実行します。自動起動や自動停止はしません。
別のフォルダーから起動したAPIの停止や、別の接続キーの表示は行いません。
接続キーはWindowsの設定ファイルやログへ保存しません。コピーはユーザー操作で行います。
実行先と表示テーマは %LOCALAPPDATA%\PLaMoLocalTranslator\controller.json に保存します。
設定を削除する場合は、アプリを閉じてこのファイルを削除してください。
