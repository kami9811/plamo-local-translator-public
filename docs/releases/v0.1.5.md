# v0.1.5 — 初回モデル取得の403を修正

新規セットアップが古い固定版モデルの取得で止まる問題を修正しました。取得できるPFN公式の固定版へ更新し、モデルとテンプレートの両方をSHA256で確認します。

```mermaid
flowchart LR
  A[初回セットアップ] --> B[PFN公式の固定版を取得]
  B --> C[モデルとテンプレートのSHA256を確認]
  C --> D[2B / 8Bで翻訳]
```

- 2B/8Bの公式GGUF・テンプレートを新しい固定コミットへ更新。
- 途中ファイルをハッシュごとに分け、別の版を混ぜて再開しない。
- 取得済みの旧モデルも利用可能。旧版を使う出力・キャッシュには、その版の記録を使う。
- 初回導入をv0.1.5へ更新し、「配布先全体の問題」という説明を訂正。

## 導入・更新

初めて使う場合は[セットアップ](../SETUP.md)。既存環境は[更新手順](../NETWORK-SECURITY.md#既存環境の更新)でコードとChrome拡張を更新してください。旧モデルの重みを取り直す必要はありません。起動・停止用アプリ0.1.1はそのまま使えます。

セットアップを改めて実行すると、選択したモデルを新しい固定版へ更新します。一括翻訳中・中断中の原稿の扱いを含め、[モデル取得と更新](../MODEL-DOWNLOAD.md)を確認してください。

## 確認したこと

隔離したMac CIで、arm64の2B、Intelの2B・8Bについて、新規の全体ダウンロード、モデル・テンプレートのSHA256、実際のCPU翻訳、終了を確認しました。Intelでは2B→8Bの切り替えも確認しています。[CI 42210069931](https://github.com/kami9811/plamo-local-translator-public/actions/runs/42210069931)

Public Python25件、Private22件、両方の型チェック・拡張ビルド・模擬APIによるブラウザー通信テストが成功。拡張ZIPにモデル・原稿・接続キーは含めません。

GPU/Metal、Apple Silicon 8B、包括的な翻訳品質評価は今回の再試験に含めません。通常の翻訳経路への外部サービス追加はありません。初回取得はインターネット接続を使います。[検証の詳細と制限](../validation/model-download/summary.json)
